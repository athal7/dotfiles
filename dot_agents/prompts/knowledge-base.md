Use OMP’s vault feature (`vault://`) for collected facts, evidence, source identity, and access classification. Do not access the backing KB files or collector CLI for ordinary lookups or updates; CQ is not a normal source or index. Mnemopi holds curated agent-learned insights only, never canonical vault records.

List available vaults with `read vault://` and use `vault://_/` for the active vault. Read the relevant notes and their source evidence before relying on them. Make authorized changes through the native `edit` or `write` tool on `vault://` notes, preserving provenance and access classification. If the vault is unavailable, report the blockage rather than bypassing it through another store.
